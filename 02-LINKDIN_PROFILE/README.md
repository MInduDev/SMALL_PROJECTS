# LinkedIn Profile Dashboard

A beginner-friendly **LinkedIn-inspired responsive profile dashboard** built using **HTML, CSS, Bootstrap, and JavaScript**.

This project is created for practicing frontend development, responsive design, Bootstrap components, and basic JavaScript DOM manipulation.

## 🚀 Live Features

* Responsive LinkedIn-style navbar
* Profile section with cover image and profile picture
* Edit Profile functionality
* Follow / Unfollow button
* About section
* Skills section
* Experience section
* Create a new post
* Like / Unlike posts
* Add comments
* Share notification
* Search posts
* Responsive design for desktop, tablet, and mobile
* Bootstrap modal for editing profile

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Bootstrap Icons

## 💻 How to Run the Project

1. Download or clone this repository.

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! No backend or installation is required.

## 📌 JavaScript Functionality

The project uses JavaScript for different user interactions.

### Follow / Unfollow

Clicking the Follow button changes it between:

```text
Follow
   ↓
Following
```

### Like / Unlike

Users can like and unlike posts. The like count changes dynamically.

### Comments

Users can open the comment box and add their own comments.

### Create Post

Users can write a post and publish it. The new post appears at the top of the feed.

### Edit Profile

Users can edit:

* Name
* Job title
* About information

The changes are displayed immediately without refreshing the page.

### Search

The search bar filters posts based on the text entered by the user.

## 📱 Responsive Design

* 💻 Desktop
